## Mote 1.0.23

### 本次更新

- **代码块行首退格修复**：光标在代码块首行行首按退格，上一块不是代码块时原来是一个死键——什么都不发生；现在会剥掉围栏把代码块还原成正文（再按一次退格即可与上一段相接）。上一块也是代码块时仍直接合并两段代码。
- **拖拽后查找高亮修复**：查找条开着时用块手柄拖拽重排（或其他块级结构变化）后，高亮层原来停在拖拽前的旧位置；现在结构一变就按当前关键词重扫，命中与高亮位置一起刷新。
- 边界验证新增 8 项全通过（表格内替换、代码块退格/删除边界、拖拽重排+撤销、查找高亮跟随、跨块替换、多选+菜单删除），此前各轮 80 项回归全通过（累计 88 项），无控制台报错。

### 构建与分发

- macOS 安装包使用 **Developer ID 签名 + Apple 公证 + stapler 票据**，离线状态下也能通过 Gatekeeper 校验。
- Windows 安装包与绿色版同步更新，构建号 `20`。

### 校验

随附 `SHA256SUMS.txt`，下载后可自行校验：

```bash
# macOS / Linux
shasum -a 256 -c SHA256SUMS.txt

# Windows
certutil -hashfile mote-1.0.23-win64-setup.exe SHA256
```

应用内「检查更新」会自动检测并升级；也可以从下载页手动安装覆盖。构建号 `20`，macOS 与 Windows 同号。

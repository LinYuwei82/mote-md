所有安装包与手册均由下载子域 dl.xiaotu.online 直接提供，与本站页面不同域名属于正常现象。Windows 绿色包为免安装压缩包，解压即可运行。

SHA256 用于确认文件完整、未被篡改。下载完成后可在终端校验：

# macOS / Linux
shasum -a 256 xiaotu-inventory-0.9.0.dmg

# Windows
certutil -hashfile xiaotu-inventory-0.9.0.dmg SHA256

输出结果应与对应下载行标注的 SHA256 完全一致；不一致请不要安装。

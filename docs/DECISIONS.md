# 决策记录（接手先读）

换机器、换人接手时先读这一页：它记录 Mote 为什么长成现在这样、哪些约束不能碰、哪些结论只是实测过的现状而非设计承诺。内容只取自本仓库的代码与文档；没有仓库依据的地方标注「未验证」。

## 一、决策时间线

### 1. 从 Qt 原生文本引擎改为「原生外壳 + 系统 WebView」

- **问题**：早期用 `QTextDocument`/自绘做编辑器（`backup/` 里留有快照），排版能力与 Markdown 语义（表格、代码块、行内标记）都要自己实现，维护成本高。
- **选择**：Qt 只做窗口、菜单、文件与打包；正文交给系统 WebView（macOS 为 WKWebView，Windows 计划 WebView2），用 HTML/CSS 渲染 Markdown。
- **理由**：排版、选择、输入法、滚动交给系统内核；前端可以用成熟的 HTML/CSS 表达块结构，迭代速度远高于自绘。重构后正文层为零第三方前端依赖（无框架、无 bundler）。
- **代价**：包体积受 Qt 制约，与架构无关。当前 zip 30,919,184 字节（约 30 MB，与 `dist/` 现有一致），解压 75 MB，其中 `libicudata` 约 32 MB、Qt 框架约 18 MB（见 `packaging/PACKAGING.md`）。想压到 40 MB 以内需要换不带 ICU 的 Qt 构建，尚未做。
- **与 Typora 的体积对比**：立项时以 Typora 作为体积参照，但仓库内没有保留当时的对比数字，**未验证**；当前可引用的只有上面这组实测值。

### 2. 行内编辑的「零位移」

- **问题**：所见即所得的行内标记（`**粗体**`、`` `代码` ``）如果渲染时把标记从 DOM 里删掉，光标偏移、`dataset.raw` 与 `textContent` 的对齐、撤销快照全部要另建映射。
- **选择**：标记字符保留在 DOM 里，用零宽 `.mk` 包裹；进入编辑态时只在光标附近显示「上标小标签」提示，正文宽度不变。
- **理由**：`dataset.raw === textContent` 这条不变量让「光标偏移 = 原文偏移」，撤销、查找、复制、选区都能直接用 DOM 的原生偏移，不需要第二套坐标系。
- **代价/降级**：做不到 Typora 那种「字里行间显示灰色标记、随光标移动淡入淡出」的效果——标记要么零宽、要么以固定小标签出现；编辑时看不到行内标记的完整原文，只能靠标签与源码模式确认。

### 3. 代码块

- **问题**：围栏（```）如果进入 DOM，会被 `textContent` 计入，破坏 `raw === textContent`；行号若放在滚动容器内，会跟着横向滚动一起跑。
- **选择**：围栏不进入 DOM（`raw` 里有，渲染时剥掉，块自带 `code` 类型表达围栏）；行号栏放在滚动容器之外，与内容同步纵向滚动。
- **理由**：围栏是块的边界信息，不需要参与文本偏移；行号固定在左侧才符合阅读习惯。
- **代价**：代码块的 `raw !== textContent`，是这条不变量的唯一例外（与表格、分隔线并列，验证脚本里显式豁免）。渲染时第一次出现滚动条会让块高少 15px，已在 `normalizeCodeScrolls()` 里用 `overflow-y` 归一化（只改 `overflow-x` 无效，横向滚动条画在纵轴空间里）。

### 4. 表格

- **问题**：表格要能「就地编辑」，但 `|` 与对齐行（`:---:`）如果作为可见字符存在，会让单元格宽度和光标位置都变复杂。
- **选择**：`|` 与对齐行以零宽标记保留在 DOM；对齐行放在一个隐藏的 `<tr>` 里。
- **理由**：编辑态可以把整张表当纯文本改，渲染态又看不到这些语法字符；对齐信息不丢，也不占版面。
- **代价**：Enter 在表格里不新增行（会破坏「一行 = 一条 raw」的对应），新增行用末格 `Tab` 或 `Cmd+Enter`；两者都在 `PACKAGING.md` 的验证表里有实测记录。

### 5. 查找与替换

- **问题**：高亮如果把 `<mark>` 插进 DOM，会改变 `textContent` 与光标偏移。
- **选择**：查找高亮用覆盖层（绝对定位的矩形），不往正文里插节点；替换只在「整段匹配且不跨标记边界」时执行，否则拒绝。
- **理由**：覆盖层不碰模型，查找期间仍可编辑；拒绝跨标记替换，避免把 `**`、`` ` ``、链接括号切坏。
- **代价**：查找按块进行，不跨块；跨标记/跨换行的替换会明确拒绝而不是「尽力而为」（见验证表）。

### 6. 图片

- **问题**：早期用 `loadHTMLString:baseURL:` 载入页面，WebKit 把页面当成「无来源」文档，拒绝一切 `file://` 子资源，相对路径图片永远 `naturalWidth=0`。
- **选择**：把页面写成文档同目录下的隐藏临时文件（`.mote-preview-<pid>.html`），用 `loadFileURL:allowingReadAccessToURL:` 载入，并注入 `<base>` 指回文档目录。
- **理由**：只有 `loadFileURL` 才授予读取同目录子资源的权限；`baseURL` 单独给不够。
- **代价**：临时文件必须落在文档目录（授权范围要求），异常退出可能残留（已在 `.gitignore` 排除，正常退出会删除）。

### 7. 撤销

- **问题**：细粒度 diff 在前端块模型上容易与输入法、跨块选区打架。
- **选择**：整篇快照 + 绝对偏移，历史栈由前端持有；渲染态/源码模式切换不切断历史。
- **理由**：实现简单、语义可预测；快照大小对普通文档可忽略。
- **代价**：超大文档（数 MB）每次输入都序列化整篇，内存与延迟随文档线性增长，未做分块优化。

### 8. 快捷键必须注册原生菜单

- **问题**：macOS 的 NSMenu 在网页 `keydown` 之前消费 key equivalent；`Cmd+Z` 甚至会走 responder chain 的 `undo:`，绕开页面。
- **选择**：所有会在 WebView 内生效的组合键都注册成原生 QAction（撤销/重做另接 `NSEvent` local monitor）。
- **理由**：否则「菜单里有、按了没反应」；`Cmd+Shift+Z` 还曾被匹配到「撤销」项（NSMenu 匹配字母时忽略 Shift）。
- **代价**：菜单项与前端处理逻辑要成对维护；新增快捷键必须检查与现有项是否重复（`MOTE_KEYLOG=1` 会打印全表）。

### 9. 右键菜单前的选区折叠

- **问题**：WebKit 在派发 `contextmenu` 之前就把多块选区折成光标，导致「转为」只作用到一块。
- **选择**：在 `mousedown`（右键）阶段保存 Range，`contextmenu` 时若点击块在保存范围内则恢复。
- **理由**：这是事件顺序决定的，只能在更早的事件里取快照。
- **代价**：需要自己判断「点击是否落在原选区内」，否则会把用户想单块操作的情况也强行扩成多块。

### 10. 工程迁移出 iCloud 与行尾统一

- **问题**：工程原先放在 iCloud「文稿」目录，构建产物每次都会触发同步，影子构建也被拖慢；双机协作还需要统一行尾。
- **选择**：迁到 `/Users/lin/Projects/mote`；构建放 `$TMPDIR/mote-build`；新增 `.gitattributes`（`* text=auto`、`*.sh eol=lf`、`*.bat/*.cmd eol=crlf`、图片与字体标 `-text`）。
- **理由**：仓库与构建都离开同步目录后，打包稳定且不产生同步噪声；行尾规则让 Windows 克隆拿到 CRLF 的批处理与 LF 的脚本。
- **代价**：迁移后旧的绝对路径脚本需要改（已改）；`.gitattributes` 生效后 Windows 侧首次检出会出现行尾差异，属预期。

## 二、硬约束（改动会连带破坏其它功能）

1. **零位移**：进入/离开编辑态不改变任何块的宽度与高度；标记必须零宽。
2. **`dataset.raw` 与 `textContent` 逐字相等**：代码块、表格、分隔线是显式例外（围栏/`|`/对齐行不进文本）。
3. **标记不进入选区复制**：复制出去应是 Markdown 原文，不能带出 UI 控件或提示标签的文字。
4. **块几何只在该变的地方变**：插入/转换只影响目标块高度与其下方块的位移，上方块 `top` 不变。
5. **撤销以整篇快照为单位**：任何会改 `raw` 的新交互都必须走同一条历史入口，否则一次撤销还原不了。

## 三、已知未解决 / 待验证

- **Windows 拖放边界**：多文件、跨目录等情形未在 Windows 上逐项实测（见 `docs/release-notes-0.3.0.md`）。
- **仅 arm64**：未做 x86_64 与通用二进制。
- **Ad-hoc 签名、未公证**：首次打开需右键「打开」或在隐私设置里放行。
- **输入法与物理按键**：中文/五笔组合态、长按连发速率、触控板手势只能人工确认，自动化只覆盖到 ASCII 与单次按键。
- **查找/替换不跨块**：跨块匹配与替换未实现；跨标记替换主动拒绝。
- **目录在源码模式隐藏**：源码模式下不显示 TOC，属现状而非缺陷。
- **Typora 体积对比数据缺失**：仓库内无存档，**未验证**。

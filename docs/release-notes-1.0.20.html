Mote 1.0.20

本次更新

  • 回车拆分块修复：对列表/引用/标题块内的回车拆分（Enter）做了一轮系统性边界检测，重写为结构感知拆分——
  • 列表/有序列表/引用项中回车：原来后半段会丢掉 -、1.、> 前缀，变成带字面符号的普通段落；现在前后两半都保留结构，列表还是列表、引用还是引用。
  • 行尾回车不多造空条目：光标在第一项末尾按回车，原来会插出一个多余的空条目；现在按行边界干净拆分。
  • 空条目回车退出结构：在空的列表项/引用行上按回车，不再无限追加空条目——第一次回车新增空条目，第二次回车退回正文（与 wolai / Notion 行为一致）。
  • 标题中间回车：后半段保留 # 前缀，不再降级成正文。
  • 边界验证新增 10 项全通过，此前各轮 54 项回归全通过，无控制台报错。

构建与分发

  • macOS 安装包使用 Developer ID 签名 + Apple 公证 + stapler 票据，离线状态下也能通过 Gatekeeper 校验。
  • Windows 安装包与绿色版同步更新，构建号 17。

校验

随附 SHA256SUMS.txt，下载后可自行校验：

# macOS / Linux
shasum -a 256 -c SHA256SUMS.txt

# Windows
certutil -hashfile mote-1.0.20-win64-setup.exe SHA256

升级说明

应用内「检查更新」会自动检测并升级；也可以从下载页手动安装覆盖。构建号 17，macOS 与 Windows 同号。

## Mote 1.0.24

### 本次更新

- **结构块块首退格修复**：光标在引用块、列表项、标题块的首行行首按退格，上一块类型不同时原来是一个死键——什么都不发生；现在会剥掉结构前缀（`>`、`-`、`#` 等）把该块还原成正文（再按一次退格即可与上一段相接）。文档首块是结构块时同样生效。
- **行内标记拆分修复**：光标在 `**加粗**` 或 `` `行内代码` `` 中间回车拆分，原来两半会各留下一个未闭合标记，渲染成字面的星号/反引号；现在拆分后自动配对平衡（前半闭合、后半重开）。
- **跨块选区转换修复**：用 Shift+方向键或鼠标拖选出多个块后，通过手柄菜单/快捷键「转为」标题、引用等，原来只作用于光标所在的单个块；现在按选区实际覆盖的所有块逐块生效，且一步撤销即可整体还原。
- **加粗开关修复**：选中整行加粗文本（含 `**` 标记本身）再按加粗，原来会套上第二层标记变成 `****文字****`；现在正确识别为取消加粗，还原为纯文本。
- 边界验证新增 18 项（第十轮块首退格/标记拆分/撤销重做/跨块删除，第十二轮表格 IME/语言切换/粘贴边界/嵌套缩进/转块矩阵）全部通过，此前 88 项回归全通过（累计 115 项），无控制台报错。

### 构建与分发

- macOS 安装包使用 **Developer ID 签名 + Apple 公证 + stapler 票据**，离线状态下也能通过 Gatekeeper 校验。
- Windows 安装包与绿色版同步更新，构建号 `21`。

### 校验

随附 `SHA256SUMS.txt`，下载后可自行校验：

```bash
# macOS / Linux
shasum -a 256 -c SHA256SUMS.txt

# Windows（PowerShell）
Get-FileHash SHA256SUMS.txt -Algorithm SHA256
```

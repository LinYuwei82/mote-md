Mote 1.0.17

本次更新

  • 块操作继续检测修复：对 ⋮⋮ 手柄 / 拖拽 / 块菜单再做一轮系统性边界检测，修复四个问题——
  • 撤销/重做收浮层：块菜单开着时按撤销或重做，整篇重建后菜单会悬空停留在新文档上；现在重建时统一收起块菜单与手柄。
  • 唯一块清空可撤销：文档只剩一块时「删除」会清空内容，但清空后的状态没有进入撤销栈，Ctrl+Z 会跳过这一步找不回内容；现在清空落一步历史，撤销找回、重做再清。
  • 删块后代码块光标落点：删除的块前面是代码块时，焦点落在代码块但光标被放到块首；现在按原文口径换算，正确落在块尾。
  • 拖拽移出窗口收尾：拖块时鼠标移出窗口松开，拖拽状态会卡住（手柄隐藏、指示线悬空）；现在按最后位置落块收尾。
  • 边界验证新增 8 项全通过，基础 15 项与上轮 13 项回归全通过，无控制台报错。

构建与分发

  • macOS 安装包使用 Developer ID 签名 + Apple 公证 + stapler 票据，离线状态下也能通过 Gatekeeper 校验。
  • Windows 安装包与绿色版同步更新，构建号 14。

校验

随附 SHA256SUMS.txt，下载后可自行校验：

# macOS / Linux
shasum -a 256 -c SHA256SUMS.txt

# Windows
certutil -hashfile mote-1.0.17-win64-setup.exe SHA256

升级说明

应用内「检查更新」会自动检测并升级；也可以从下载页手动安装覆盖。构建号 14，macOS 与 Windows 同号。

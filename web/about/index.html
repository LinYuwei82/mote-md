小兔在线

我们做三款自研桌面软件：小兔进销存、DevCard、Mote。它们有一个共同点——数据留在使用者的电脑上，装完就能用。

三款产品

小兔进销存面向小微门店，管商品、开单据、看库存、出报表；一套程序既能单机使用，也能在一台电脑上做服务器、让局域网内其他人用浏览器访问。

DevCard面向物业设备管理，把设备台账整理成 A4 设备管理卡，导出 PDF 或直接打印，方便塑封后贴到设备上。

Mote是一款 Markdown 查看器与编辑器，用原生薄外壳加系统 WebView，不打包 Electron 一类运行时，安装包只有 1.7 MB 左右，源码以 AGPL-3.0 公开。

技术取向

  • 核心逻辑用 C++20 编写，桌面外壳尽量薄，渲染交给系统 WebView（macOS WKWebView、Windows WebView2）。
  • 不依赖外部数据库服务：小兔进销存与 DevCard 用本地文件 / SQLite 保存数据，备份就是复制目录或文件。
  • 前端零框架、零构建，减少打包体积和长期维护成本。
  • 发布包提供 SHA256，下载后可以自行核对完整性。

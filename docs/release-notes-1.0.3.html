RELEASE NOTES

Mote v1.0.3

在线更新改用统一清单 · 2026-11-18

本版重点

这一版改的是"应用怎么检查更新"，编辑与导出功能与 1.0.2 完全一致，没有需要适应的行为变化。

更新链路变化

项1.0.3 之前1.0.3
清单文件 两个平台各一份（latest.json / windows.json） 双平台合并为一份 manifest.json（Schema v2）
清单校验 只校验安装包的 SHA256 清单本身先做 Ed25519 验签，验签不通过直接放弃本次更新
签名实现 — 内置 TweetNaCl 实现，不引入第三方运行时依赖
macOS 签名密钥 与 Sparkle 共用一把 清单签名与 Sparkle 签名各用一把，互不影响

升级方式

从 1.0.2 手动升级到 1.0.3

1.0.2 及更早的客户端读取的是已经下线的旧清单，无法自动发现 1.0.3，请手动下载本版安装包覆盖安装一次。从 1.0.3 起后续版本都能自动更新。

之后

启动 10 秒后自动检查一次，之后每 24 小时一次；也可以走菜单「检查更新…」手动触发。

系统要求

  • macOS 14（Sonoma）或更高，Apple Silicon
  • Windows 10 或更高（x64），需要 WebView2 运行时（Windows 11 自带）

完整性校验

各安装包的 size 与 sha256 以更新清单为准： updates/stable/manifest.json。 清单可再用发布公钥验签（方法见 docs/更新清单Schema-v2.md）。

安装包未做 Windows 代码签名。首次运行时 Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。

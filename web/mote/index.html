Mote

原生薄外壳 + 系统 WebView 的 Markdown 查看 / 编辑器。正文按块编辑，渲染交给系统 WebView，不引入 Electron 一类运行时。

功能

像看文档一样看，像改文字一样改

正文按空行切块。平时保持排版效果，点中哪块就改哪块，离开后按 Markdown 原文重新渲染。

  • 所见即所得块编辑：点中某块就地显示该块原文，其余块保持排版；离开后重新渲染。
  • 代码块：语法高亮（内置轻量实现）、左侧行号与语言徽标；点击徽标即可改语言。
  • 表格与分隔线：表格就地编辑单元格、分隔行与对齐；分隔线可直接选中修改。
  • 目录：由标题自动生成，点击跳转，Cmd/Ctrl+Shift+L 开关。
  • 查找替换：Cmd/Ctrl+F 跨块跳转；会破坏标记结构的替换会被拒绝并说明原因。
  • 源码模式：Cmd/Ctrl+E 在渲染态与纯文本 Markdown 之间切换。
  • 图片：粘贴或拖入图片自动落盘到文档同目录的 assets/，插入相对路径。
  • 任务列表：- [ ] 渲染成可点击复选框，点击即改写原文，一次撤销可还原。
  • 字数统计：状态栏显示「中文 N 字 · 英文 M 词」，中文按字符、英文按词计数。
  • 深色模式：默认跟随系统，也可手动切换；切换只换配色，不动文档与编辑状态。
  • 导出：单文件自包含 HTML（样式内联、图片内嵌），或 A4 多页 PDF。
  • 在线更新：启动后自动检查，也可手动触发；macOS 走 Sparkle 验签，Windows 应用内下载并校验 SHA256。
界面

块编辑与代码块

正文保持排版效果，代码块带左侧行号、语言徽标与语法高亮；底部状态栏显示文件路径与字数统计。

技术取向

薄外壳，不背运行时

macOS 外壳
C++20 + AppKit + WKWebView，发布包不含 Qt
Windows 外壳
C++20 + Win32 + WebView2
前端
零框架、零构建，两端共用同一份渲染与编辑资源
安装包
DMG 约 1.7 MB，.app 约 4.1 MB（含 Sparkle.framework）
许可证
AGPL-3.0，源码在 Gitee 公开

已知限制

  • macOS 包只含 arm64 切片，Intel Mac 需自行构建。
  • 源码模式是纯文本编辑，没有语法高亮。
  • 查找替换的单个命中不会跨块边界或行内标记。
  • 深色模式覆盖正文区域，菜单栏仍是系统原生外观。

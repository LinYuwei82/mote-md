## 三、三项复跑

### 第一项：复制保留格式

**操作**

1. 打开一篇同时含标题（`#`/`##`）、无序列表、有序列表、普通段落，以及**带语法高亮的代码块**（代码围栏写 ` ```js ` 即可）的文档。
2. 从标题开始拖选，跨过列表、段落与代码块。
3. `Cmd+C`。
4. 分别粘贴到：
   - **TextEdit 富文本**（新建文稿直接 `Cmd+V`，不要先「转换为纯文本」）；
   - **Mail 新邮件正文**；
   - **纯文本编辑器**（TextEdit「格式 → 转换为纯文本」后 `Cmd+V`，或终端）。

**期望**

- 富文本目标：标题层级可见、列表保留项目符号/编号、段落分隔正常、代码块保持等宽与底色。
- 富文本目标：代码块里**有高亮颜色**（关键字、数字、函数名不是同一种颜色），且**没有** `js` 这类语言徽标单独占一行。
- 富文本目标：**不出现** `#`、`- `、`1. `、`*`、反引号、`[](...)` 等 Markdown 源码前缀，无 `.mk`、gutter、行号、零宽字符残留。
- 纯文本目标：只有干净文本——标题不带 `#`、列表项不带 `- `、行内代码不带反引号、链接只剩可见文字。

**判据**

| 通过 | [ ] |
| 不通过 | [ ] |
| 不适用 | [ ] |

> 失败线：代码块多出 `js` 一行、高亮颜色缺失（整段同色）、出现 Markdown 源码前缀或零宽残留，任一命中即判不通过。

### 第二项：空选区提示

**操作**

先准备基线：复制一段已知文本（如「基线内容」），确认 `Cmd+V` 能粘出。

依次测三种情况，每种都先 `Cmd+C` 再 `Cmd+X`：

1. **完全没选中**：正文里点一下，光标折叠、无选区。
2. **选中一个空段落块**：点进空行后用 `Shift+方向键` 扩选，或从空行拖选。
3. **选中仅含空格的块**：在某段里输入几个空格成新段，再选中该块。

**期望**

- 状态栏提示：复制为「没有可复制的内容：先选中文字」，剪切为「没有可剪切的内容：先选中文字」。
- 剪贴板不变：三种情况做完后 `Cmd+V` 粘出的仍是「基线内容」。
- `Cmd+X` 不删内容：块数不变、正文不变、标题栏不出现 `*`（不产生未保存改动）。

**判据**

| 不通过 | [ ] |

### 第三项：块外粘贴

**操作**

1. 打开已有内容的文档，把光标点到**最后一块下方的空白区**（正文之外）。
2. 剪贴板放一段纯文本，`Cmd+V`。
3. `Cmd+S` 保存，关闭后重新打开。
4. 反向检查：`Cmd+Ctrl+Shift+4` 截图到剪贴板，光标放回正文 `Cmd+V`。

**期望**

- 自动补出一个段落块并插入文本，光标在插入内容之后。
- 保存后磁盘文件包含该段文字，重开后仍在。
- 反向检查：图片落盘到文档同目录的 `assets/`，正文插入 `![](assets/paste-<日期>-<时间>.png)`，状态栏提示「已保存图片：assets/...」；文档未保存时提示「图片未插入：当前文档还没有保存位置，请先保存 .md 文件」，且不写任何位置。
- 若光标确实无法落在块外（点击空白区后仍进入最后一块），可判「不适用」，但要记录实际现象，不要直接判通过。

## 四、失败时怎么记

每项不通过都要留下：

1. **现象**：哪一步、哪个目标、哪一段出错（粘贴结果尽量附原文）。
2. **截图**：Mote 中的选区 + 粘贴目标 / 状态栏提示。
3. **Console 输出**：Console.app 里 Mote 的报错行。
4. **日志**：`MOTE_KEYLOG=1` 启动时 stderr 中相关片段（`NATIVE -> JS clipboard copy/cut/paste`、快捷键分发、保存）。

处理原则：**先在 `mac/clipboard` 上修**，不要直接合并到 `main`；修完重跑对应项并在 PR 里记录失败现象与修复提交。

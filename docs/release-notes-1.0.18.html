Mote 1.0.18

本次更新

  • 块操作「转为」修复：对 ⋮⋮ 块菜单与右键「转为」再做一轮系统性边界检测，修复两个静默无操作的问题——
  • 表格转正文/标题/列表：表格块「转为正文」原来原地不动，转为标题/列表时还会把竖线 | 与对齐行当成内容带过去；现在正确剥出单元格文字，转正文时逐行拆成独立段落。
  • 分割线转正文：--- 块「转为正文」原来同样原地不动；现在得到空正文块，可以继续输入。
  • 斜杠菜单插入表格/分割线时不再可能把已有的表格或分割线块当成「空块」原地替换。
  • 边界验证新增 9 项全通过，此前各轮 36 项回归全通过，无控制台报错。

构建与分发

  • macOS 安装包使用 Developer ID 签名 + Apple 公证 + stapler 票据，离线状态下也能通过 Gatekeeper 校验。
  • Windows 安装包与绿色版同步更新，构建号 15。

校验

随附 SHA256SUMS.txt，下载后可自行校验：

# macOS / Linux
shasum -a 256 -c SHA256SUMS.txt

# Windows
certutil -hashfile mote-1.0.18-win64-setup.exe SHA256

升级说明

应用内「检查更新」会自动检测并升级；也可以从下载页手动安装覆盖。构建号 15，macOS 与 Windows 同号。

如何核对 SHA256

SHA256 用于确认文件完整、未被篡改。下载完成后在终端执行命令，输出结果应与对应下载行标注的值完全一致；不一致请不要安装。

# macOS / Linux
shasum -a 256 mote-1.0.23-macos-arm64.dmg

# Windows（PowerShell）
Get-FileHash .\mote-1.0.23-macos-arm64.dmg -Algorithm SHA256

# Windows（命令提示符）
certutil -hashfile mote-1.0.23-macos-arm64.dmg SHA256

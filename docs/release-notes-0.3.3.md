# Mote v0.3.3 — Windows 版

Mote 是一个用 **C++20 + Qt 6** 写的 Markdown 编辑/查看工具，编辑体验参照 Typora：原生外壳 + 系统 WebView，编辑时即时渲染，没有左右分栏，进出编辑块光标不位移。

0.3.3 把代码块体验补齐：代码块内部右上角新增复制按钮，语言徽标改成可搜索的语言选择器，头栏与代码正文之间的横向分隔线去掉；Windows 端新增导出 PDF（WebView2 `PrintToPdfAsync`，A4 分页）。此外修复了超长文档导出截断、复制按钮位置、装饰性箭头与头栏横线等问题。

> Windows 与 macOS 使用同一版本号 v0.3.3；Windows 产物已完成，macOS 包已打出，校验值见文末「校验」。

## 0.3.3 变更

- **代码块复制按钮**：按钮固定在代码块内部右上角，默认半透明、悬停显形，点击出现对勾并在约 1.2 秒后恢复；不抢焦点、不进入编辑态、不新增撤销步骤。复制内容为代码正文纯文本，单行块与 30 行块均逐字节一致，不含行号、语言名或箭头。
- **语言选择器**：点击语言徽标打开带搜索框的下拉，支持 `py`、`脚本` 等中英文过滤，方向键 + Enter 选择，Esc / 点外部 / 再点徽标关闭；无匹配时可按 Enter 写入自定义语言；Plain Text 可清除围栏；选择语言会立即重着色、置脏并进入撤销栈，撤销/重做可还原围栏与代码。
- **头栏去横线**：去掉头栏与代码正文之间的横向分隔线，保留代码块外框与行号栏竖线；头栏高度仍为约 30.5px，单行块保持紧凑，渲染态/编辑态切换不跳动。
- **Windows 导出 PDF**：`Ctrl+P` 或「文件 → 导出 PDF…」；A4（595×842pt）、左右约 18mm、上约 21–25mm，无页眉页脚与页码；代码语法高亮与代码块底色、表格底色保留，等宽字体正常；中文可搜索、可复制；401 段文档 21 页、800 段文档 41 页，段落无缺失/重复、无空白尾页；导出前若语言下拉打开会自动关闭，纸面无搜索框、候选清单、徽标、箭头或复制按钮；导出不改变 dirty 状态、不新增撤销步骤。
- **0.3.2 之后的修复**：超长文档导出不再截断；复制按钮从框外浮层移回块内右上角；去掉徽标旁的装饰性箭头；去掉头栏横向分隔线。

## 系统要求

- macOS 14 及以上（Apple Silicon，arm64）：构建目标为 `-mmacosx-version-min=14.0`，更早的系统未经测试
- Windows 10 1809 及以上 / Windows 11，64 位
- 需要 WebView2 Runtime（Win11 和多数 Win10 自带；缺失时程序会提示并给出下载入口）
- 安装后约 34.7 MB，绿色版解压后约 34.7 MB

## 下载与安装

二选一：

1. `Mote-Setup-0.3.3.exe`：按用户安装到 `%LOCALAPPDATA%\Programs\Mote`，不需要管理员权限；安装时可选择关联 `.md`，卸载时会还原你原来的默认程序
2. `Mote-Windows.zip`：解压后直接双击 `Mote.exe`，不写注册表

## 首次启动被拦截

本版未做代码签名，SmartScreen 会提示「Windows 已保护你的电脑」。点「更多信息」→「仍要运行」即可，只需一次。

## 已实现功能（Windows 已实测）

- 打开 `.md`、新建、编辑、`Ctrl+S` 保存
- 标题、段落、列表、任务列表、引用、代码块、表格、分隔线、链接、图片的渲染与就地编辑
- 代码块语法高亮、行号、目录侧边栏、字体缩放、加粗/斜体快捷键、撤销
- 代码块复制按钮与可搜索语言选择器（含自定义语言、Plain Text）
- 导出 PDF（A4、无水印页眉页脚、代码块与表格底色保留、中文可搜索）
- 文档同目录的相对路径图片正常显示
- 系统级拖放：拖入 `.md` 直接打开；拖入图片复制到文档同目录的 `assets/` 并插入引用；不支持的类型显示禁止光标、不插入内容
- 剪贴板：复制/剪切带 HTML、空选区提示、块外粘贴兜底与干净撤销、三条入口各只写一次、文件列表剪贴板不写入正文
- 安装版支持 `.md` 关联，卸载可还原原有默认程序

其余 macOS 已有能力随共享前端一并可用，但未在 Windows 上逐项实测。

## 已知限制

- 仅提供 x64；安装向导界面为英文
- **换目录后页面会重新加载**：另存为或新建到另一个目录后，页面会重新加载，滚动位置回到顶部、撤销历史与当前编辑态会重置。这是为了让新目录下的相对图片能正常显示（系统 WebView 的资源访问范围在加载页面时就固定了，只改页内 `<base>` 不够），不是 bug
- 复制出的 HTML 里 `<pre>` 仍保留 `class="code-block"` 与空的 `code-scroll` 容器；非列表节点会带 `list-style-type: disc`。不影响富文本目标显示
- 编辑菜单「粘贴」的插入位置与原生光标位置一致，可能落在块首；快捷键与右键菜单粘贴落在块末/右键处
- 行内代码复制到 Word 后字体为 `Menlo`（macOS）/ `Consolas`（Windows），与页面内使用的 JetBrains Mono 不同，这是为兼容外部应用而写的回退字体栈
- 系统级拖放已接入并实测：`.md` 直接打开、图片落盘到 `assets/` 并插入引用、不支持的类型显示禁止光标；多文件与跨目录等边界情况未逐项实测
- 150% 高 DPI 仅按 `QT_SCALE_FACTOR=1.5` 模拟验证，未在真实 150% 缩放的显示器上逐项复核
- 锚点链接、脚注、数学公式尚未支持
- 仅处理本地文件，不含云端同步
- 未做代码签名与公证：Windows 首次运行需按上文通过 SmartScreen，macOS 需手动放行
- 旧版 WebView2 Runtime（低于 108）未在真机验证，仅按当前 Runtime（157.0.4341.46）实测
- 导出后内存不回落到导出前：800 段文档实测约 +44MB 的打印缓冲，导出结束进程仍持有该内存
- 语言选择器的输入法候选窗未在真机手敲验证，仅用合成组字事件验证了 Enter/Esc 与过滤行为
- **macOS 侧四项复核未完成**：未保存对话框按钮文案、块间 gap 粘贴、源码态粘贴、Word 行内代码字体此前没有结论，本轮也未逐项复核，不视为已验证

## Mote 1.0.19

### 本次更新

- **块操作退格/回车修复**：对 ⋮⋮ 块菜单、退格合并与回车拆分再做一轮系统性边界检测，修复四个问题——
  - **同类型块退格合并**：相邻两个列表/引用/标题/有序列表块在块首按退格，原来会把结构标记直接拼进正文，产生 `- a- b`、`# a# b` 这类坏 Markdown；现在标题剥掉第二块前缀并成一行，列表/引用逐行保留标记合成一个块。
  - **块首退格死键**：光标停在列表/引用/标题块最前（前缀标记右侧）按退格原来毫无反应；现在同类型时与上一块合并，否则剥掉前缀还原成正文，再按一次即可与上一段相接。
  - **分割线回车销毁分割线**：光标在 `---` 块内按回车，分割线会凭空消失变成两个空段；现在回车改为在分割线后插入空正文块，分割线留在原地。
  - **代码块转正文**：多行代码块「转为正文」原来在一个块里塞进硬换行；现在与列表/引用/表格同口径，逐行拆成独立段落。
- 边界验证新增 9 项全通过，此前各轮 45 项回归全通过，无控制台报错。

### 构建与分发

- macOS 安装包使用 **Developer ID 签名 + Apple 公证 + stapler 票据**，离线状态下也能通过 Gatekeeper 校验。

### 校验

随附 `SHA256SUMS.txt`，下载后可自行校验：

```bash
# macOS / Linux
shasum -a 256 -c SHA256SUMS.txt

# Windows
certutil -hashfile mote-1.0.19-win64-setup.exe SHA256
```

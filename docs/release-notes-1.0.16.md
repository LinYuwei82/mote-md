## Mote 1.0.16

### 本次更新

- **块操作边界修复**：1.0.15 上线的 ⋮⋮ 手柄 / 拖拽 / 块菜单做了一轮系统性检测，修复两个边界问题——
  - **切源码模式收浮层**：之前切到源码模式时块菜单可能悬空停留，其动作会作用到已重建的旧 DOM；现在切换时统一收起块菜单与手柄。
  - **「转为正文」口径统一**：块菜单把多行列表/引用转为正文时，之前会把硬换行塞进单块；现在与右键/快捷键路径一致，逐行拆回独立段落，且一次撤销即可还原。
- 边界验证 13 项全通过：表格块/代码块拖拽、未提交编辑后拖拽、拖拽撤销重做、唯一块删除、删除聚焦块焦点落邻块、Esc 与外部点击关菜单、源码模式浮层收起、列表/引用拆分转换、TOC 联动更新；基础功能回归 15 项全通过。

### 构建与分发

- macOS 安装包使用 **Developer ID 签名 + Apple 公证 + stapler 票据**，离线状态下也能通过 Gatekeeper 校验。
- Windows 安装包与绿色版同步更新，构建号 `13`。

### 校验

随附 `SHA256SUMS.txt`，下载后可自行校验：

```bash
# macOS / Linux
shasum -a 256 -c SHA256SUMS.txt

# Windows
certutil -hashfile mote-1.0.16-win64-setup.exe SHA256
```

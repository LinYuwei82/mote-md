## Mote 1.0.15

### 本次更新

- **块操作（参照 wolai / Notion）**：文档现在支持鼠标驱动的块级编辑——
  - **⋮⋮ 悬停手柄**：指针移到任意块上（或块获得焦点）时，块左缘出现拖动手柄；所有块类型（段落、标题、列表、引用、代码块、表格、分隔线）统一生效。
  - **拖拽重排**：按住手柄上下拖动即可移动块，落点实时显示插入指示线，拖到视口上下边缘自动滚动；重排一步进撤销栈，可随撤销/重做回退。
  - **块菜单**：单击手柄弹出——在上方插入、在下方插入、复制副本、删除，以及「转为」（正文 / 标题 1-3 / 无序列表 / 有序列表 / 引用 / 代码块），与右键「转为」同一套转换语义。
- **原文零损伤**：手柄与菜单都是编辑器浮层，不进入块内容；块移动时原文与块间空行随块走，序列化逐字一致，PDF / HTML 导出不含任何手柄痕迹。

### 构建与分发

- macOS 安装包使用 **Developer ID 签名 + Apple 公证 + stapler 票据**，离线状态下也能通过 Gatekeeper 校验。
- Windows 安装包与绿色版同步更新，构建号 `12`。

### 校验

随附 `SHA256SUMS.txt`，下载后可自行校验：

```bash
# macOS / Linux
shasum -a 256 -c SHA256SUMS.txt

# Windows
certutil -hashfile mote-1.0.15-win64-setup.exe SHA256
```

### 升级说明

应用内「检查更新」会自动检测并升级；也可以从下载页手动安装覆盖。构建号 `12`，macOS 与 Windows 同号。

RELEASE NOTES

Mote v1.0.0

2026-11-17 · 首个稳定版，两端在线更新模块完成

Mote 是一个 C++20 写的 Markdown 编辑/查看工具。原生 Win32 / AppKit 外壳 + 系统 WebView2 / WKWebView， 没有左右分栏，编辑时即时渲染，进出编辑块光标不位移。

从 0.3.10 到 1.0.0，历经两个迭代（0.3.11、1.0.0），两端原生外壳稳定，在线更新模块完整落地。

本版亮点

  • 两端在线更新完整落地 — Windows 自研 WinHTTP + CNG SHA256 + Inno Setup 静默安装；macOS Sparkle + EdDSA 验签。手动检查、启动自动检查、后台每 24 小时检查齐全。
  • Windows 更新弹窗 UI — 进度条 + 实时百分比（67% — 450 KB / 670 KB）、取消按钮、跳过此版本记忆、发布说明超链接、安装包与绿色版分别走不同安装路径。
  • 锚点链接修复 — 文档内 #标题 跳转、重名 -1 / -2 后缀、导出 HTML 自动补 id="安装步骤" 等 GitHub 风格锚点。
  • 绿色版更新路径 — 下载校验后应用自动退出并打开所在文件夹，用户手动解压覆盖；安装版则 /RELAUNCH=1 静默安装自动重启。
  • 0.3.11 修复 — versionSegments 数字溢出保护、绿色版更新路径统一 dirty 检查、发布脚本校验正则兼容 PowerShell 5.1。
  • 下载页发布脚本自动化 — publish_windows.ps1 自动读版本号、算 SHA256、生成 windows.json、上传 OSS、线上回读校验；publish_site.ps1 校验 12 个下载链接 200 后上传。

系统要求

  • Windows：Windows 10 / 11，x64。需要 WebView2 Evergreen Runtime（Windows 11 自带；Windows 10 若缺失，安装程序会提示）。运行库静态链接 /MT，目标机无需安装 VC++ 可再发行包。
  • macOS：macOS 11（Big Sur）或更高。

从旧版本升级

  • 安装版：文件菜单 → 检查更新…，确认后自动下载、校验 SHA256、静默安装并重启。
  • 绿色版：下载校验后会自动退出 Mote 并打开所在文件夹，手动解压覆盖即可。

已知限制

  • Windows 安装包未做代码签名，首次运行可能出现 SmartScreen 提示，选「更多信息 → 仍要运行」即可。
  • 绿色版无法自我替换（Mote.exe 被占用），更新后需手动解压覆盖。
  • 断网 / 下载中断没有自动化覆盖，异常路径靠手动验证。
  • 真实干净环境（全新 Windows / Mac 账户）的首次安装没有自动化覆盖。

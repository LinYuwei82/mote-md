RELEASE NOTES

Mote v1.0.2

Windows 自动更新链路修复 · 2026-11-18

本版重点

这一版是 Windows 侧的发布链路修复，功能与 1.0.1 相同。若你已经用 1.0.1，此版本没有需要适应的行为变化。

修复内容

问题修复
Windows 版本检查不到更新 安装包内嵌的更新清单地址已切换到 mote/updates/stable/windows.json，与当前线上目录一致
发布目录结构不统一 安装包、绿色包统一放在 mote/，更新清单统一放在 mote/updates/stable/

下载

Windows 安装版（推荐）：按用户安装，无需管理员权限，更新时静默覆盖并自动重启。

该版本安装包已随历史清理下线，请到下载页获取最新版本：manifest.json / 下载页。

Windows 绿色版：解压即用；应用内更新会在校验通过后退出并打开所在目录，由你解压覆盖。

安装包未做代码签名。首次运行时 Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。应用内更新走 HTTPS + SHA256 校验，不经过浏览器，不会触发该提示。

升级方式

安装版

打开 Mote → 菜单「检查更新...」→ 下载并安装，程序会自动退出、静默安装并重新启动。

绿色版

菜单「检查更新...」→ 下载完成后 Mote 会退出并打开所在文件夹，把 zip 里的文件解压覆盖到原目录即可。

系统要求

  • Windows 10 或更高版本（x64）
  • WebView2 运行时（Windows 11 自带；Windows 10 如缺失，安装包会引导安装）

完整性校验

各安装包的 size 与 sha256 以更新清单为准： updates/stable/manifest.json。 下载后可用 Get-FileHash -Algorithm SHA256 比对。

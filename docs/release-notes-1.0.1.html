RELEASE NOTES

Mote v1.0.1

Windows 外壳缺陷修复 · 2026-11-17

本版重点

这一版没有新增功能，全部是 Windows 外壳的缺陷修复，集中在快捷键、链接打开和文件保存三块。之前反馈的部分「奇怪问题」都能对应到下面的条目。

修复内容

问题表现修复
浏览器快捷键开关从未生效 Ctrl+Shift+S、Ctrl+F 等被 WebView2 内部吃掉，外壳菜单收不到 调整初始化顺序，快捷键开关在 WebView 创建之后再设置
文档内链接打开规则不完整 链接到另一个 .md 打不开；file: 与相对路径不支持 与 macOS 端对齐：http/https/mailto 交系统；file: 与相对路径解析成本地文件，.md 应用内打开；其余 scheme 拒绝
链接白名单可被绕过 带前导空格的 javascript: 仍会进入 ShellExecute 先剔除首尾空白与控制字符再解析 scheme，非法字符按本地路径处理并由存在性检查兜底
保存改动文件行尾 打开 CRLF 文档后保存，整篇变成 LF，Git 里表现为全文件 diff 记录原文件行尾风格，写回时按原样还原
状态栏消息重放 页面重载后再次弹出上一条旧提示 消息送达即清空缓存
文件对话框内存泄漏 每次打开/保存泄漏一块 COM 内存 释放 GetDisplayName 返回的字符串
更新下载界面信息不足 进度只显示已下载 MB，没有百分比 读取 Content-Length，进度条与百分比同步显示
更新弹窗缺少说明入口 看不到这一版改了什么 清单新增 notes_url，弹窗里出现「查看完整更新说明」链接

下载

Windows 安装版（推荐）：按用户安装，无需管理员权限，更新时静默覆盖并自动重启。

下载 Mote-Setup-1.0.1.exe

Windows 绿色版：解压即用；应用内更新会在校验通过后退出并打开所在目录，由你解压覆盖。

下载 Mote-1.0.1-win64-portable.zip
安装包未做代码签名。首次运行时 Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。应用内更新走 HTTPS + SHA256 校验，不经过浏览器，不会触发该提示。

升级方式

安装版

打开 Mote → 菜单「检查更新...」→ 下载并安装，程序会自动退出、静默安装并重新启动。

绿色版

菜单「检查更新...」→ 下载完成后 Mote 会退出并打开所在文件夹，把 zip 里的文件解压覆盖到原目录即可。

系统要求

  • Windows 10 或更高版本（x64）
  • WebView2 运行时（Windows 11 自带；Windows 10 如缺失，安装包会引导安装）

完整性校验

各安装包的 size 与 sha256 以更新清单为准： updates/stable/windows.json。 下载后可用 Get-FileHash -Algorithm SHA256 比对。

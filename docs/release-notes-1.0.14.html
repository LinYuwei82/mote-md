Mote 1.0.14

本次更新

  • 表格列宽算法升级（参照 wolai / Notion 标准 auto 布局）：在 1.0.13 按内容分列的基础上，落实完整的标准表格布局算法——
  • 长词保护（min-content）：每列宽度不低于最长不可断段（长英文单词、URL）的渲染宽度，链接和英文词不再被拦腰折行；中文可逐字断行，不额外占宽。
  • 增长因子分配：空间紧张时先保证每列最小内容宽，再按各列「可增长空间」比例分配剩余宽度，长文本列获得更多空间、短标签列保持紧凑。
  • 超宽表格横向滚动：当所有列的最小内容宽都放不下时（如 9 列长英文词），表格保持完整宽度、容器横向滚动，与 wolai / Notion 行为一致，不再压碎内容。
  • 空格精确测量：单元格 | 内容 | 两侧参与布局的空格计入测量，消除窄列差 1 个字宽被折行的边界情况。
  • 导出继承：PDF / HTML 导出继续复用同一渲染结果；纸面宽度固定，超宽表格在纸面按页宽压缩，编辑器内横向滚动不带入 PDF。

构建与分发

  • macOS 安装包使用 Developer ID 签名 + Apple 公证 + stapler 票据，离线状态下也能通过 Gatekeeper 校验。
  • Windows 安装包与绿色版同步更新，构建号 11。

校验

随附 SHA256SUMS.txt，下载后可自行校验：

# macOS / Linux
shasum -a 256 -c SHA256SUMS.txt

# Windows
certutil -hashfile mote-1.0.14-win64-setup.exe SHA256

Mote 1.0.29

新功能：多窗口并行编辑

  • 一个窗口一篇文档：打开多个文件时每个文件独立成窗，可同时对照、分开编辑，互不干扰。
  • 外部打开一律新窗口：从访达 / 资源管理器双击、拖放到程序图标、命令行打开文件，都会在独立新窗口打开，不再替换当前正在编辑的文档。
  • 重复打开自动聚焦：文件已在某个窗口打开时，再次打开会直接跳到那个窗口，不会产生重复窗口。
  • 新建窗口：菜单「文件 → 新建窗口」，快捷键 Ctrl/Cmd + Shift + N。
  • 撤销各自独立：每个窗口拥有独立撤销栈，在一个窗口撤销不会影响其他窗口。
  • 安全退出：关闭窗口或退出应用时，未保存的窗口会逐个询问保存 / 不保存 / 取消，不会丢内容。

新功能：「最近打开」列表

  • 菜单「文件 → 最近打开」记录最近 10 个文件，最新在前、自动去重。
  • 文件已不存在的条目自动置灰；支持一键「清除记录」。

构建与分发

  • macOS 与 Windows 同版本同步发布，构建号 26。
  • macOS 安装包使用 Developer ID 签名 + Apple 公证 + stapler 票据。
  • 1.0.28 的全部行为（启动与打开提速、跨目录免重载、macOS 1.0.27 闪退修复等）保持不变。

校验

随附 SHA256SUMS.txt，下载后可自行校验：

# macOS / Linux
shasum -a 256 -c SHA256SUMS.txt

# Windows（PowerShell）
Get-FileHash SHA256SUMS.txt -Algorithm SHA256
